# StudioFlow OS

AI project workspace with agents, tasks, docs, memory, and tools.

## Folder Name Note

This folder is named `StudioFlowAgentOS` because `AIProjects/StudioFlowOS` already exists for a different project. The product name from the chat is still **StudioFlow OS**.

## Concept

StudioFlow OS is a project workspace where AI agents, documents, tasks, tools, GitHub, workflows, and project memory live together.

It is not just chat and not just a workflow builder. It is a project operating system for AI-assisted work.

## Smallest Useful Loop

```text
Project
  -> Chat
  -> Save Note
  -> Create Task
  -> Retrieve Context
```

## MVP Features

- Create projects.
- Add project notes and docs.
- Create tasks.
- Create agents.
- Chat with an agent inside a project.
- Agent reads project memory.
- Save AI output as a note or task.

## First MVP Flow

```text
Create Project
  -> Add project goal
  -> Create QA Agent
  -> Ask QA Agent for test cases
  -> Save output as Note
  -> Convert selected items into Tasks
```
