# Idea: StudioFlow OS

## One-Liner

StudioFlow OS is an AI project workspace where users manage projects, documents, tasks, agents, tools, and shared project memory.

## Mission

Help people manage projects with AI agents that understand project context.

## Core Objects

- Project.
- Task.
- Note.
- Document.
- Agent.
- Memory.

## Non-Goals For MVP

- No visual workflow builder.
- No multi-agent orchestration.
- No marketplace.
- No huge tool catalog.

## MVP Success

A user can do this within 5 minutes:

1. Create a project.
2. Add notes and documents.
3. Chat with a project agent.
4. Save important information to memory.
5. Create tasks from AI outputs.

## Product Rule

Every feature must answer:

```text
Does this help the user finish project work faster?
```

If the answer is no, do not build it yet.
